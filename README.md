# go-aws-s3-io
[![License: MIT](https://img.shields.io/badge/Licence-MIT-brightgreen)](https://opensource.org/license/mit)

This library exposes `io.Reader` and `io.Writer` interfaces to read and write data into and from Amazon AWS S3 Buckets. 

## Installation Instructions

Add [terminatewithextremeprejudice/go-aws-s3-io](https://github.com/terminatewithextremeprejudice/go-aws-s3-io) as a dependency to your project:

```cli
go get github.com/terminatewithextremeprejudice/go-aws-s3-io
```
